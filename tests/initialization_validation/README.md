# 初始化更新审查与验证

审查提交：`69ab4ce`（Init）。当前工作区还包含本次修正与新增算例。

## 执行顺序

`ReadParameters` → `make_user_hooks` → 可选 `initialize_units` → 构造网格并读取
初态 → 固定最终配置 → `initialize` → 填边界 → 初始输出 → 注册源项 → 时间积分。

这个顺序适合单位初始化：MESA 半径、密度、压力、速度转换和后续引力常数都能
使用 hook 设置的单位。未注册单位 hook 的旧算例保留原有默认行为。
`initialize_units` 应调用 `init_unitsystem_MLT` 或 `init_unitsystem_RHOLV`，
由它们更新派生单位和物理常数。

MESA / 文件初态读入后，`initialize` **仍然执行且仍要求注册**。因此文件初始化
算例应把它用作检查、填外介质或注入能量；若照搬原来的解析初态函数，会覆盖
刚读入的状态。MESA 外侧 padding 原本没有状态行，必须由此 hook 补齐。

## 发现并修正的问题

1. **非均匀网格的反射边界几何不对称。** 原实现对 ghost faces 按边界单元宽度
   等距外推，但反射状态取自相邻不同宽度的有效单元。PLM 使用中心距离计算斜率，
   因而左右重构不再严格镜像，出现非零壁面质量/能量通量。
   MESA 和 mesh 文件初始化现在对反射边界镜像真实有效网格面；所有有效区面不变。
   修正前的 MESA 试跑到第 10,000 步，质量已减少约 1.60375e-4 个代码质量单位
   （相对 1.95201e-5）；修正后完整 0.1 s 运行的最大相对质量变化为 1.24e-14。
2. **profile-only 输入被静默忽略。** 以前只有 `init_mesh_from_file` 和
   `init_profile_from_file` 同时为 true 才读 profile。现在 profile 可独立配合
   框架生成的网格使用。
3. **`build_mesh` 的 const 接口兼容性。** 新实现需写回文件网格边界，改用了可写
   `SimulationConfig&`；原来的 const 调用会无法编译。补回 const 重载，通过
   配置副本构造；需要获得文件派生边界的调用者仍应传入可写配置。
4. **`interp_linear` 声明和定义不一致。** 头文件按值传参，实现按 const 引用传参，
   调用头文件声明会链接失败。现已统一为 const 引用，并有实际调用测试。
5. **初始化开关冲突缺少检查。** 原来 MESA 分支会静默忽略同时启用的 mesh/profile
   文件选项。现在明确拒绝互斥组合，并检查已启用模式的文件名非空。

同时移除了 `table.h` 对整个配置/网格头文件的无关依赖，显式包含其所需标准库。
两个旧单元测试（Godunov 和 integrator）的准备代码漏建几何缓存；此问题在
`ee4aa5b` 已存在。已补上 `build_geometry()`，没有更改求解器算法。

仍需注意的输入/模型约束：

- mesh 文件是等长列的矩形表，因此当前格式要求各轴有效单元数相同；32×32
  可用，32×48 不能直接由此格式表达。它是张量积直角网格，不是逐单元坐标表。
- 通用 profile 文件使用代码单位，按 x 最快的顺序逐个有效单元读取；必须提供
  `rho vx vy vz pre gamma` 六列。MESA 读取器则从 cgs 和 logR 单位显式转换。
- 当前 MESA 路径仅支持球对称一维；main 中 padding 固定为线性、内外各 100 个
  （相应方向不需要补网格时不使用）。柱坐标并未实现，不能因选项名称出现就视为可用。
- MESA 压力通过统一的理想气体 gamma 转成能量，未导入 MESA EOS、`gamma1`、
  原始内能或组分。这是加载到现有理想气体求解器，不等价于继续完整 MESA 物理模型。

## 一阶全隐式实现方案

以下为待实现设计，当前延长运行仍使用原有显式 RK2。建议先实现固定网格、理想气体、
一维球对称的 backward Euler，覆盖本次 MESA 算例，再扩展多维和高阶空间重构。
时间一阶本身不要求空间一阶；首版选择 PCM 是为了减小耦合范围和避开限制器切换，
须显式指定，不能在用户选择 PLM 时静默降阶。网格半径、体积、面积与 gamma 在一步内固定。

### 离散方程与现有接口

对有效单元的 U=(rho, momentum, energy_density) 解

    R_i = U_i - U_i_old - dt * L_i(U, t_old + dt) = 0
    L_i = -(A_R F_R - A_L F_L)/V_i + S_geometry + S_gravity + S_other

所有通量、压力、几何源项、重力加速度及重力做功均在候选新状态计算。初始化的
thermal bomb 仍只执行一次，不进入残差评估。未知量只有有效单元；每次残差评估
均在临时网格上调用 FillBoundary(candidate, t_old+dt, hooks)，ghost 由新状态生成。
候选状态及差分扰动都要重新填边界，边界对有效单元的依赖必须计入 Jacobian。

建议保留 MeshBlock、Conserved、RiemannSolver 和 advance_one_step 的外部接口，新增：

| 位置 | 变更 |
| --- | --- |
| src/time/integrator.h、intergator.cpp | 增加 BackwardEuler 枚举、解析与分派 |
| src/time/backward_euler.cpp | 尝试时间步、Newton 迭代、拒绝回滚、成功提交 |
| src/time/implicit_system.h/.cpp | 有效单元打包、残差、缩放、Jacobian 装配 |
| src/utils/banded_solver.h/.cpp | 带选主元的带状线性求解，封装外部后端 |
| src/config/config.h/.cpp | 读入独立的隐式容差、初始/最大步长、迭代与重试上限 |
| src/source/gravity.cpp | 将壳层几何系数及给定包围质量计算引力的公式提取为共享函数 |
| src/source/source.h | 增加可选的内置源项标识/线性化耦合元数据，未知用户回调不假设局部 |

目前 evaluate_RHS 同时返回 RHS 和 min(CFL limit, source limit)。应先提取一个不决定
步长的空间算子评估接口，返回 RHS 和诊断；显式包装保持原调用顺序、求和顺序及 CFL
行为，隐式残差仅使用算子值。源项上限须区分显式稳定性、精度与物理硬上限，未知用户
源项默认保留其硬限制；不能笼统忽略所有 source_dt_limit。当前 MESA 的几何/重力源项
不设置有限步长上限。

隐式参数独立于 cfl/cfl_max；原来的 cfl_max<=0.5 仍用于显式积分器。
隐式步长不能再由 dt=min(dt_next, dt_CFL) 决定，实际声学 Courant 数只用于诊断。
现有 wave_timestep 是可变的串行全局记录，差分通量评估会覆盖它；隐式诊断应复制到
每次评估的返回值，不依赖最后一次扰动留下的全局数值，首版不并行调用该接口。

### 自引力的局部化

当前 spherical_self_gravity 累加全部内层壳质量，因此用 U 直接装配完整 Jacobian 时，
重力部分并非三对角。冻结旧时刻引力不满足这里的全隐式目标。

可以在每个单元增加内部求解未知量 M_i，表示左侧面的包围质量：

    M_0 = M_core
    M_i - M_(i-1) - rho_(i-1) V_(i-1) = 0,  i >= 1
    D_i = rL^2 + rL*rR + rR^2
    alpha_i = (rR^2 + 2*rL*rR + 3*rL^2)/(4*D_i)
    g_i = -3*G*(M_i + alpha_i*rho_i*V_i)/D_i
    S_momentum = rho_i*g_i
    S_energy = momentum_i*g_i

这些系数和 gravity.cpp 当前实现一致。新块未知量为 (rho, momentum, energy_density, M)。
质量约束与流体残差一起 Newton 求解；M 只存放在隐式工作区，不改变 Cell 或 CSV 格式。
收敛时约束保证它与累计壳质量一致，提交前还需用现有累计公式独立检查重力与最终残差。
辅助质量约束过松会形成引力误差，必须单独缩放和检验。
隐式残差装配需通过显式的源项适配接口，把内置球对称重力替换为使用候选 M 的版本，
不能先调用原 SourceList 累加一次重力，再加一遍辅助变量重力；也不能在残差中仍按 rho
累计 M、却在 Jacobian 中把它当独立未知量。显式路径继续使用原累计方式。

PCM 通量仅依赖左右单元，内侧反射与当前外侧禁止流入边界都是局部边界，所以该算例
得到 4x4 块三对角系统。可封装 LAPACK 的带状 LU 选主元求解，避免构造稠密矩阵、
显式求逆或使用无选主元的简化消元。当前约 2,699 个单元，共 10,796 个未知量，
带宽不随单元数增加；固定带宽时装配和线性求解成本随单元数线性增长。
Makefile 已有 LDLIBS 扩展点，隐式后端宜作为可选构建能力，未启用时保持原显式构建依赖。

该带状假设不自动适用于周期首尾耦合、任意用户源项/边界或多维模型。首版应明确检查
支持范围（本例 NDIM=1、NCOMP=NUSER=0、无真空）；不能把未知非局部耦合默认为零。
后续 PLM 会增宽 stencil，通用多维可接稀疏 Newton-Krylov 与预条件后端，共用残差接口。

### Newton 求解与时间步控制

每次迭代解 J*delta=-R，再作带阻尼更新。通量可先复用现有 exact Riemann solver，
对单个面的左右守恒量做经过缩放且保持物理合法的有限差分，组装局部通量导数；
几何和重力项采用解析导数。不可逐个扰动全域变量并为每一列完整重算全域 RHS，
那会把一维装配成本放大到平方量级。局部差分须包含守恒量到原始量转换和边界映射。
差分步长、Riemann 内迭代误差及 Newton 目标精度要协调，以方向导数检查确定误差平台。

1. 保存 U_old，选候选 dt，用旧状态作初猜并由它计算 M 初猜。
2. 在候选新状态填边界，评估残差并组装 Jacobian，求 Newton 修正。
3. 回溯线搜索保证 rho>0、E-momentum^2/(2*rho)>0，且缩放残差下降。
   不用直接截断负压来掩盖不收敛，以免破坏守恒。
4. 密度、动量、能量、包围质量分别缩放；动量参考尺度包含 rho*c_s，不能只用
   接近零的旧动量。尺度含绝对下限并在一次 Newton 求解内固定，避免低密度大气被忽略。
5. 缩放残差与修正量同时达标才接受；修正很小而残差大属于停滞。失败时缩短 dt，
   从完整旧状态重试。所有候选、边界和最终验证成功后一次性提交；Newton 内不输出。

第一步可以从原 CFL 步长起步，后续增长受精度控制而非声学稳定性硬限。
基准版本建议用一个完整 backward Euler 步与两个半步的差值估计时间误差：
在相同旧状态、相同输出时刻比较，使用分量缩放的误差范数；接受完整一步解以保留
单步 backward Euler 方程，半步解仅用于估计误差。对这个接受策略，完整步的局部误差
估计取 2*(U_full-U_two_half)。一阶方法该差值为 O(dt^2)，
新步长按安全系数乘 error^(-1/2) 调整，并限制增长倍率、最小/最大步长及重试次数。
这样每次尝试需三次非线性求解，成本明确，但能避免仅凭 Newton 收敛就盲目取大步。
非线性误差必须显著小于时间误差目标，后续才优化更便宜的误差估计。

### 守恒与验收

每个界面通量只计算/采用一份，并以相反符号加入两侧体积积分方程。无源项时，
总量变化由边界通量和体积加权的非线性残差控制。当前重力做功离散并不自动保证
气体总能量加引力势能严格守恒；须分别验证流体守恒、引力做功与全能量误差。
隐式积分也不会自动修复压力与重力离散不平衡。

实施顺序为：先做保持旧结果的 RHS 拆分；再实现无重力 PCM 的 backward Euler；
接入几何源项、中央引力和上述自引力约束；最后加入误差控制并运行 MESA 比较。
至少验证以下行为：

- 原 Euler/RK2 的三组兼容性输出逐字节不变。
- 残差确定性、局部 Jacobian 与全域方向差分一致、自引力辅助质量与原累计值一致。
- 反射壁面质量/能量零通量，拒绝步与失败边界不改变已接受状态。
- 光滑问题固定网格、连续减半 dt 时与细时间步解相比呈一阶时间收敛。
- 声学 Courant 数大于 1 时能收敛且保持正状态，同时量化幅度衰减，不能仅以不发散验收。
- Sod 激波位置、接触面耗散；非均匀球网格的静力平衡漂移和重力做功误差。
- 相同网格/初态/EOS/PCM 下，显式小步与隐式同物理时刻比较质量、压力、速度及爆炸波位置；
  现有 PLM+RK2 长跑另作参考，避免把重构改变造成的差异归因于时间积分。
- MESA 外大气的巨大动态范围、内侧注能初期的非线性收敛，以及总耗时和接受/拒绝步数。
