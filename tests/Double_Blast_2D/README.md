# 两个膨胀波相撞（2D）

两个高压圆盘在静止、均匀气体中膨胀，各自向外推动压缩波；向内传播的两道波
在中间相撞，形成高压压缩区，再向外发出后续波系。这里的“膨胀”指高压气体膨胀，
其向外推进的波并不是单纯的稀疏波。无重力，无需改动流体求解器。

默认配置：

| 参数 | 值 |
|---|---|
| 区域 | `[0,2] × [0,1.5]` |
| 活跃网格 | `192 × 144`，两个方向格长相同 |
| 圆心 | `(0.75,0.75)`、`(1.25,0.75)` |
| 半径 | `0.12` |
| 初始密度、速度 | `rho=1`、`vx=vy=0` |
| 圆盘内/背景压力 | `10 / 1` |
| gamma | `1.4` |
| 结束时间 | `0.22` |
| 边界 | 四面反射 |

初始化按单元中心采样。圆心位置取横向域长的 0.375/0.625、纵向中点，
半径取较短域长的 0.08；改区域大小时这些位置会随之缩放。
默认运行关注边界明显影响之前的碰撞。延长时间后会包含反射壁产生的波。
这是二维非线性相互作用演示与守恒/对称性回归测试，没有采用一维 Sod 或 Sedov
解析解来衡量精度，也不把两个单独爆炸的解线性叠加当参考解。

从 FLARE 根目录运行：

```bash
make -C tests/Double_Blast_2D -j4 test
make -C tests/Double_Blast_2D animate
```

- `test` 编译、运行、检查，并保存末帧和中心压力峰值时刻的诊断图。
- `check` 只检查已有输出。
- `animate` 检查输出并导出 GIF；安装 ffmpeg/libx264 时还导出 MP4。

检查内容：初始化、正密度/压力、质量与气体总能量守恒、左右/上下镜像对称性，
以及中心压力和密度是否实际上升。检查器要求两个方向格数均为偶数，中心诊断
使用中央 `2×2` 单元的平均值，因此加密时该诊断区域也会变小。
脚本报告边缘活跃单元相对背景的最大压力偏离，辅助判断是否受到边界影响。
过早结束、尚未发生中心压缩的运行会失败；这是碰撞检查的预期行为。

输出：

- `output/run.log`：本次运行的快照清单，检查与绘图只读其中列出的文件。
- `output/diagnostics/metrics.csv`：守恒、对称性、中心压力/密度等指标。
- `output/diagnostics/final.png`、`collision_peak.png`：末帧/中心压强峰值图。
- `output/animations/double_blast.gif`、`double_blast.mp4`：四面板动画。

依赖 numpy、matplotlib、Pillow，MP4 另需 ffmpeg/libx264。动画使用实际保存的帧，
不做时间插值；每帧播放时长相同，标题显示物理时间。色标固定，压力图用对数色标，
便于同时看到初始高压区和较弱的传播波。右下角压力曲线展示完整运行，标记指出当前帧。

推荐通过 `make test` 运行以刷新清单；框架的裸 `make run` 不生成新的运行清单。
需要更清晰的波前时，可将格数改成 `256×192` 或 `384×288`，同时换输出目录。
这些只是加密，不改变物理区域或初始两个圆盘的大小与距离。

默认配置已运行至 `t=0.22`（398 步、82 个快照）。中央 `2×2` 单元平均压力
在保存时刻 `t≈0.06494` 达到约 `7.174`，其后回落。最大质量/能量相对漂移约
`2.2e-16`，最大反射对称误差约 `4.2e-11`，边缘最大压力偏离约 `4.7e-7`。
这些是本次离散计算的诊断值，不是解析解或针对不同分辨率的固定验收值。
