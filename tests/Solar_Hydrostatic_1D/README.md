# 太阳尺度的球对称静水平衡恒星

这个算例建立质量约为一个太阳质量、半径为一个太阳半径的自引力恒星，
初始速度为零，演化使用现有球坐标 Godunov + PLM/MC + RK2。
中心点质量为零，恒星引力全部来自网格中的气体。

模型采用 n=3 Lane–Emden 多方球的密度分布；它用于测试恒星的静水平衡，
不是包含核反应、辐射输运、电离和真实成分分层的标准太阳模型。
半径是多方解密度降为零的位置，并非由光学深度定义的光球半径。

## 运行

在项目根目录执行：

```bash
make -C tests/Solar_Hydrostatic_1D -j4
make -C tests/Solar_Hydrostatic_1D test
```

`test` 运行完整模拟、记录日志、检查初态和演化漂移，并生成诊断图。
再次执行会替换本算例输出目录下的 `solar_XXXXXXXX.csv`。
仅重新检查已有结果：

```bash
make -C tests/Solar_Hydrostatic_1D check
```

只运行模拟而不生成检查报告：

```bash
make -C tests/Solar_Hydrostatic_1D run
```

C++ 需要支持 C++17；检查脚本需要 Python、NumPy、Matplotlib。

## 单位和物理规模

采用 IAU 2015 B3 的标称太阳半径和太阳引力参数：

| 量 | 数值 |
| --- | --- |
| 长度单位 L0 | 6.957e10 cm |
| 引力参数 GM_sun | 1.3271244e26 cm^3/s^2 |
| 质量单位 M0=GM_sun/G_cgs | 1.9884098707e33 g |
| 时间单位 t0=sqrt(L0^3/GM_sun) | 1592.8585 s |
| 速度单位 L0/t0 | 436.7620 km/s |
| 密度单位 M0/L0^3 | 5.90527 g/cm^3 |
| 压力单位 M0/(L0 t0^2) | 1.12650e16 dyn/cm^2 |

因此计算单位中 G=1、恒星主体质量 M=1、半径 R=1。
`t_end=5` 对应 7964.29 秒，约 2.21 小时。
温度单位保持 1 K；当前理想气体演化不直接使用温度。
初始中心密度约 76.39 g/cm^3，中心压力约 1.245e17 dyn/cm^2。
这些中心值属于该多方模型，不应当作真实太阳中心参数。

`initialize()` 调用 `physcon::units.init_unitsystem_MLT()`，统一更新计算常量；
不会把已经用计算单位表示的网格再转换一次。
原有算例未调用该初始化时仍使用默认 cgs 常量。

## 初态构造

求解 n=3 Lane–Emden 方程：

```text
dtheta/dxi = -mu/xi^2
dmu/dxi   = xi^2 theta^3
theta(0)=1, mu(0)=0
```

使用原点级数起步，再用 RK4 积分至第一零点：
`xi1 = 6.89684862`、`mu1 = 2.01823595`。
按 M=R=1 缩放：

```text
rho_c       = xi1^3 / (4*pi*mu1)
rho_star(r) = rho_c * theta(xi1*r)^3,  r < 1
M_star(r)   = mu(xi1*r) / mu1
```

不含外部气氛时，这对应 P=K rho^(4/3) 的 n=3 多方平衡。
演化的绝热指数取 gamma=5/3；多方指数描述初始分层，绝热指数描述扰动，
两者不需要相等。本算例不施加冷却、速度阻尼或额外抵消引力的源项。

为了避免表面直接接真空，叠加密度极低的气氛：

```text
rho_atm(r) = 1e-8,                                      r <= 1
rho_atm(r) = 1e-8 * exp[G*(1/r-1)/0.02],                 r > 1
```

外部气氛近似等温，p/rho=0.02；气氛的总质量只有约 4.5e-8 M_sun。
最终压力不是简单裁剪多方压力，而是在加入气氛自引力后重新积分：

```text
dp/dr = -rho(r) G M(<r)/r^2
```

从最外层 ghost 的外侧面向内积分，外侧压力为 `rho_atm*0.02`。
密度和压力均用球体积权重积分到有限体积单元；速度初始化为零。

计算域是 0 到 1.1 R_sun，默认 512 个有效径向单元。
中心采用反射边界；外侧 ghost 保持上述平衡气氛、速度为零。
外边界是固定气氛边界，并非严格的无反射边界；有效单元不被重置。

## 验证范围

目前的流体通量与重力源项没有严格配平，不能保证离散 RHS 为零。
本算例提供满足连续静水平衡的初态，并测量演化后的有限精度偏离。
`check.py` 对全部已保存快照检查以下条件：

| 检查 | 阈值 |
| --- | --- |
| 初态质量相对 1 M_sun 的偏差 | < 1e-5 |
| 初态连续静水平衡残差的加权 RMS | < 1e-3 |
| 总质量相对初态漂移 | < 1e-5 |
| 密度体积加权 L1 偏离 / 初始质量 | < 1% |
| 质量加权 RMS Mach 数 | < 0.01 |
| 包含 99% 质量的半径漂移 | < 1% |
| 包含自引力势能的总能量漂移 | < 1% |

同时检查初始速度为零、正密度/正压、有限数值、Lane–Emden 零点和质量常数、
以及是否到达指定终止时间。静水平衡残差用初始压力剖面求导，并在 r<0.9、
排除最内两个单元后计算；它不等同于求解器的离散 RHS。
引力势能按各壳层内密度常数精确积分。外边界有小量通量，域内总能量并非
严格封闭系统的守恒量。所有“最大漂移”均指已保存的快照，不是每一个时间步。

低质量气氛和表面层的相对误差、局部速度可能明显大于恒星主体；
质量加权指标不能证明气氛也被精确保持。诊断会单独报告最终气氛最大速度。
需要长期演化、表面波或风的问题时，应进一步改进平衡重构和外边界。

实际验证到 t=5（约 2.21 小时）的已保存快照结果：

| 指标 | 256 层 | 512 层（默认） |
| --- | --- | --- |
| 初态连续平衡残差 RMS | 2.651e-4 | 6.630e-5 |
| 最大密度 L1 相对偏离 | 4.302e-4 | 7.778e-5 |
| 最大质量加权 RMS Mach | 4.734e-4 | 1.094e-4 |
| 最大 99% 质量半径相对漂移 | 6.382e-4 | 1.170e-4 |
| 最大总能量相对漂移 | 1.270e-4 | 1.589e-5 |
| 最大总质量相对漂移 | 4.666e-10 | 1.285e-10 |
| 末态气氛最大速度 | 54.6 km/s | 7.70 km/s |

主体误差随网格加密下降；气氛仍存在较明显运动，尤其粗网格下。
默认 512 层的主体密度偏离约 0.0078%，不能解读为每个低密度表面单元
都有同样小的相对误差。

## 输出

- `output/solar_XXXXXXXX.csv`：原始模拟快照，数值为计算单位，`x` 是径向坐标中点。
- `output/model.json`：物理单位、中心值、Lane–Emden 常数。
- `output/initial_profile_cgs.csv`：初态壳层边界、体积中心、平均密度和压力、外侧面包围质量，全部为 cgs。
- `output/metrics.json` 和 `metrics.csv`：漂移指标与检查结果。
- `output/equilibrium.png`：初末密度/压力、末态速度和漂移曲线。
- `output/run.log`：由 `make test` 生成的完整运行日志。

改变 `nxa` 可以比较网格收敛，其他单位和模型参数不变。
气氛常数位于 `user_problem.cpp`；改变它们后需要重新编译。
