# 激波撞密度球（3D）

真正的三维球体，非二维圆柱。区域 `[-0.5,1.5]×[-0.5,0.5]×[-0.5,0.5]`，
默认 `64×32×32` 网格。球心 `(0.3,0,0)`，半径0.18，球内 rho=5、外部 rho=1，
初始 p=1、速度为零，gamma=1.4，无重力。球面按单元中心判定。

x=-0.35 处放一个向右的 Mach 2 激波。激波后 rho=8/3、p=4.5、vx≈1.479；
x 下边界输入该状态，其余边界使用零梯度出流。t_end=0.45，观察球体被压缩、加速及绕流。

```bash
make -C tests/Shock_Cloud_3D -j4 test
make -C tests/Shock_Cloud_3D animate
# 真正三维坐标中的正交剖切动画：
python3 animate3d.py tests/Shock_Cloud_3D/output mesh_cloud --field rho
```

检查初值、正密度/压力、球体压缩和加速，以及 y/z 方向反射对称性。
默认最高密度约15.13，高密度区位置向右移动约0.110。
高密度核心使用权重 `max(rho-3,0)` 估算位置与速度，**不是物质示踪量**，
不能据此报告严格的云质量损失、混合率或某团固定流体的位移。
流入流出边界允许质量和能量变化，检查器不作闭域守恒断言。

默认球半径只有约5.8格，适合快速集成测试，无法解析细小剥离涡旋或收敛的云破碎时间。
更清晰的演示可用 `128×64×64`；计算和输出开销明显上升。
常用云压碎时间 `t_cc=sqrt(5)*0.18/(2 sqrt(1.4))≈0.170`，
激波最早接触球体约在 t=0.199，因此当前末帧约为首次接触后1.48个 t_cc。

`make check` 分析已有输出；`test` 更新 `output/run.log`，所有分析只读此清单。
默认动画是三维模拟的中心 XY 截面；另一个命令生成三维正交切面。
指标/末帧在 `output/diagnostics/`，动画在 `output/animations/`。
依赖 numpy、matplotlib、Pillow，MP4 另需 ffmpeg/libx264。
