# CCSN_Simple 验证

运行完整验证并分析结果：

```bash
python3 tests/CCSN_Simple/validation/run.py --jobs 2
python3 tests/CCSN_Simple/validation/analyze.py tests/CCSN_Simple/output_validation/<运行目录>
```

依赖现有 C++ 工具链，以及 Python 的 numpy、matplotlib。所有计算完成后再运行分析。
`--cases single_512 mass01_512` 可选择部分实验；`--output <新目录>` 可指定输出位置。
拒绝覆盖已有目录。完整套件包含 14 个实验。

脚本复制当前 `user_problem.cpp` 和参数，在独立目录编译验证主程序，调用原有求解器、边界条件、引力源和时间积分器。
生产用初始条件、参数、求解器和 `output/` 均不修改。输入文件和框架源码的 SHA-256 写入 `provenance.json`。
适配器依赖明确的源代码片段；若生产初始条件改变而片段不再匹配，会报错，需重新检查适配器。

实验包括：

- 单格注能：256、512、1024 格。
- 固定加热质量 0.1 个太阳质量：256、512、1024、2048 格。
- 固定加热质量下，大气密度乘 0.01 或 100。
- CFL 从 0.2 降至 0.1。
- 外边界从 1100 扩至 1500 个太阳半径，752 格保持近似相同径向步长。
- 加热质量改为 0.03、0.3 个太阳质量。
- 不注能对照。

所有爆炸实验瞬时注入 1.6e51 erg；这里的固定质量加热按质量分配能量，最后一个单元接收剩余质量对应的能量，在整个单元内平均。
这不是完整的 SNEC 时间和空间加热函数。低于一个单元质量的加热区无法分辨：512 格时 0.03 个太阳质量实验与单格注能相同。
`heating_mass` 为质量权重的目标值，`heated_cell_support_mass` 为实际接收能量的完整单元总质量。

`driver.cpp` 在每个接受的时间步记录 `diagnostics.csv`，并在代码时间 0、10、20、30、40、50、75、100 保存快照。
仅为对齐快照时刻而截短相应时间步；这会与常规运行产生轻微的时间步序列差异。
CSV 快照保留生产输出的单位头；诊断表的数值使用代码单位，转换系数在各实验的 `model.json` 中。

能量账使用气体内能、动能、中心质量引力势能与包层自引力势能。
势能按分段常密度球壳积分，自引力只计一次。越过外边界的能量包括焓通量和势能通量。
边界输运由每步起终状态的梯形积分估计，未直接导出 RK2 阶段通量，因此残差包含诊断积分误差。
CFL 对照及激波出表面前的残差用来辅助判断这一误差。

前沿指标是最外侧满足 `p/p_initial > 10`（另测 100）且向外速度大于 100 km/s 的单元外界面。
根据到达指定半径的时间估算区间平均传播速度。这是有限分辨率下的前沿代理，不是光球速度、物质终端速度或精确的间断轨迹。
两种压力阈值给出相同位置，不代表不存在网格或阈值误差。

`v_0001`、`v_001`、`v_01`、`v_1` 分别表示：至少 0.001、0.01、0.1、1 个太阳质量的域内气体达到的速度阈值。
它们不是对应气体的平均速度。物质离开外边界后不再纳入这些质量统计。
全时段极值可能来自注能刚开始的瞬态；`post_t10_max_*` 排除代码时间小于 10 的启动阶段，`t40_*` 提供同时刻比较。

分析会检查完成时间、全部接受时间步的正密度与正压强、快照有限性、切除质量、注能预算、快照与诊断积分的一致性。
数值记账筛查要求质量残差小于初始域内质量的 1e-5，能量残差小于注能量的 1e-4（零注能时以内能归一化）。
这些阈值不代表模型的物理精度。空间收敛采用球壳体积加权的守恒量限制与 L1 差异，保留实际误差，不把有限分辨率差异自动标为通过。

输出包括 `summary.json`、`summary.csv`、`validation.png`、`validation.pdf`。
