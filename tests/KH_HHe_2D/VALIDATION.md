# H/He KH 演示运行记录

新算例使用 IdealGas_Mixed、两种中性组分、exact、PLM/MC、RK2 和 CFL=0.35。64² 预跑与默认 128² 运行都完成到 300 s；两条剪切层均形成涡旋并卷入另一侧的组分。

| 指标 | 64² | 128² |
| --- | --- | --- |
| 步数 | 1782 | 3586 |
| 快照数 | 32 | 62 |
| 末态 H 位于初始 He 区域的质量占总 H 质量 | 17.23% | 16.29% |
| 末态 He 位于初始 H 区域的质量占总 He 质量 | 17.23% | 16.29% |
| 末态 `0.1<X_H<0.9` 单元的质量占总质量 | 37.44% | 34.48% |
| 最大质量加权 vy RMS | 1.4075e5 cm/s | 1.5238e5 cm/s |

初态 vy RMS 约 2519.7 cm/s。占比指标包含有限体积平均及数值扩散，不能作为分子扩散速率，也没有据此声明网格收敛。

默认 128² 运行的全部 62 帧检查通过：

- 总质量、H 质量、He 质量、总能量的最大相对误差均为 2.3e-16 以下。
- 总动量误差以总质量×5e5 cm/s 归一化，小于 6.2e-17。
- `X_H+X_He` 的最大误差为 1.51e-14；质量分数满足检查器的 1e-12 舍入容差，没有在输出时重新归一化或裁剪。
- mu 与 `1/(X_H+X_He/4)` 一致；T 与 `P*mu/(rho*R_g)` 的最大相对误差为 4.5e-16 以下。
- 密度、压力、温度为正且有限；双能量累计修正为 0。
- 横向流动增长、H 跨入初始 He 区域、组分边界沿 x 变形三项演示检查均通过。

这不是恒压平移测试：KH 演化过程中压力和密度会变化，不能再要求它们始终保持初值。128² 的末态最小压力约 69.16 dyn/cm²，最小密度约 7.98e-11 g/cm³。
