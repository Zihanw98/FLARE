# 多层守恒 RK2 局部时间步（`lts_rk2`）

独立实现位于 `src/time/lts_rk2.cpp`，入口为 `advance_lts_rk2`。
原有 `euler`、`rk2`、`lts_euler` 继续独立使用。没有新增积分器类或层级类；
递归函数、单元预测数组和面通量累积数组完成子循环。

## 使用

```ini
time_integrator = lts_rk2
lts_max_levels = 8
cfl = 0.2
cfl_max = 0.5
reconstructor = PLM
limiter = MC
```

可直接使用 `tests/CCSN_MESA_day13/parameters_lts_rk2.txt`。
支持固定网格、一维 Cartesian / spherical、PCM / PLM / PLM_corrected；
PCM 至少一层 ghost，PLM 两层。周期边界要求 Cartesian 且两端均为 periodic。
`lts_max_levels` 与 Euler LTS 共用，默认 2，可取 1–16；8 层的最大步长比为 128:1。
最大层数是上限，实际步长比受 CFL、源项上限、层间缓冲和终止时刻限制。

## 局部 RK2 与慢区预测

空间离散后的守恒方程为

\[
\frac{dU_i}{dt}=L_i(U,t)
=\frac{A_{i-1/2}F_{i-1/2}-A_{i+1/2}F_{i+1/2}}{V_i}+S_i(U,t).
\]

同步大步长为 \(H\)，层级 \(\ell\) 的步长为 \(h_\ell=H/2^\ell\)。
每个大步开始重新选层；大步内部层级保持不变。根据初始 Riemann 波速，选满足
\(h_\ell\leq\mathrm{CFL}\,\Delta x_i/a_i\) 的层级，随后扩展缓冲区，
使相邻重构邻域的层级差不超过 1。

在一个局部步的起点 \(t_i\)，计算

\[
k_{1,i}=L_i(U(t_i),t_i),\qquad U_i^*=U_i^0+h_i k_{1,i}.
\]

慢区向其内部任意细分时刻 \(t\) 提供

\[
\widetilde U_i(t)=U_i^0+(t-t_i)k_{1,i}.
\]

这个预测用于 **PCM 和 PLM 两者**。PLM 的整个重构邻域都先预测到阶段时刻，
然后从守恒量转换到原始量并重新计算斜率。不能拿不同时间的邻居直接算空间斜率。

无层级差时，第二阶段用 \(U^*\) 计算 \(k_2\)，结果就是标准 Heun / SSP-RK2：

\[
U^{n+1}=U^n+\frac h2(k_1+k_2).
\]

## 跨层面：两侧共用同一个时间积分

每个面由相邻两单元中**更细的层级**负责。例如慢区走 \(H\)，快区走两步 \(h=H/2\)。
快区第 \(m\) 个子步给出面通量积分

\[
I_f^{(m)}=A_f\frac h2\bigl(F_f^{(m,0)}+F_f^{(m,1)}\bigr).
\]

慢区在整个 \(H\) 上使用的就是 \(I_f=I_f^{(0)}+I_f^{(1)}\)。
每次产生积分，向左单元记 \(-I_f^{(m)}\)，向右单元记 \(+I_f^{(m)}\)。
快单元每个子步结算；慢单元等其局部步完成再结算。这避免两侧各算各的积分造成不守恒。
周期边界的首尾面也只求解和累计一次。

一个层级的实际顺序如下：

1. 计算起点通量和源项，为本层单元保存 \(U^0,k_1,S^0\)。
2. 若有更细层，递归执行两个半步；细层需要的慢区状态由上述预测提供。
3. 到本层终点，构造第二阶段：本层用 \(U^*\)，更慢层用对应时刻预测，
   更细层用已经到达该终点的更新状态。重新填边界。
4. 对本层负责的面计算终点通量，累积梯形积分；跨细层的面已经由细层累计，不能重复累计。
5. 重新计算本层终点源项，更新

\[
U_i^{\rm new}=U_i^0+
\frac{I_{i-1/2}-I_{i+1/2}}{V_i}
+\frac{h_i}{2}\left[S_i(U^{(0)},t_i)+S_i(U^{(1)},t_i+h_i)\right].
\]

首个子步与父层起点的状态、时刻相同，因此复用该起点的通量及源项。
第二个子步必须重新计算。

## 为什么线性预测足够得到二阶时间精度

对平滑的半离散解，慢区预测的状态误差为 \(O(h_{\rm slow}^2)\)。
在光滑通量/源项下，它引起的 RHS 误差也是 \(O(h_{\rm slow}^2)\)；
对子步积分再乘时间长度并累加到整个大步，得到 \(O(H^3)\) 的局部误差。
梯形通量和源项积分也有 \(O(H^3)\) 的局部误差，所以在固定空间网格、
有界时间步比且稳定的条件下，得到全局 \(O(H^2)\) 时间误差。

因此不需要先知道慢区修正后的终点，也不需要二次时间插值。
这里不能直接把完整 Euler LTS 操作执行两遍再取平均：那并不自动构成每个跨层面的
二阶时间积分。

这是对平滑解的时间精度陈述。PCM 空间精度仍是一阶；限制器切换和激波附近不能保证二阶。
虽然每个局部步采用 Heun，整个跨层耦合没有给出通用 SSP/TVD 或非线性稳定性证明。

## 源项、边界和失败处理

每个阶段都构造完整网格的同一时刻近似状态，再调用源项和用户边界。
因此球几何压力项、自引力的包围质量、用户非局部源项均重新计算；没有冻结整步自引力。
边界和源项的回调时刻可能因递归而重复或回退，回调必须按传入状态/时刻求值，
不能通过调用次数或隐藏可变状态推进物理量。

源项每次独立获得正无穷的步长上限，检查各项及合计的 10% 状态变化估计。
这些限制保守地约束整个 \(H\)，而不只是当前细步。刚性源项依然会限制显式方法。
非零源项从真空创造气体暂不支持。

源项变化检查使用阶段缓存（`source_rho`、`source_velocity`、`source_half_v2`、
`source_density_allowance`、`source_momentum_allowance`、`source_internal_allowance`），
缓存密度、速度、半速度平方及三个尺度的 10% 额度。六个普通数组每个大步分配一次，
在其子步之间复用内存；额度沿用原式的运算顺序和舍入值。
每次 `evaluate_sources` 都先令 `source_cache_ready=false`，由第一个源项的
`change_limit` 在原有检查循环内填充；同阶段的其他独立源项及合计检查直接复用。
因此两个源项时，每个单元的原始量转换、状态校验和声速计算由三次降为一次。
没有源项时，不分配这些数组的元素，也不填充缓存。

缓存只在一次源项阶段求值内有效。下一 RK 阶段、下一子步及重试中的阶段求值均重新填充，
不能因 `stage` 对象地址相同而沿用旧值。每个源项的非有限值、真空及独立变化限制检查仍保留；
10% 阈值、限制公式、源项累加次序和对大步长 H 的约束均未调整。

初始同步状态仍计算精确的源项步长上限，用于选择大步 `H`。
后续 RK 阶段已知道当前尝试的 `H`，因此只检查它是否超过 10% 变化限制，
不再为每个单元累积精确的最小上限。`change_limit` 此时以正无穷/零表示通过/超限；
源项回调主动给出的上限仍独立检查，重试则用减半后的新 `H` 重新检查。

乘法快速路径在 `(2*H)*abs(rate) < allowance` 时直接接受该分量，
其中 `allowance = 0.1*scale` 在首次填充阶段缓存时计算，`2*H` 在扫描前计算。
额外的倍数 2 仅用于留出宽裕的浮点判定余量，不改变原来的 10% 阈值。
其余情况回退到原式 `H > (0.1*scale)/abs(rate)`，包括接近阈值及快速路径无法
处理的溢出、下溢和非有限中间量，以保持原有舍入判定。零变化率始终不限制步长。
辅助函数 `detail::source_change_exceeds` 合并在现有 `src/time/lts_rk2.cpp` 中，
在现有 `integrator.h` 内提供内部声明供数值边界测试调用；没有新增文件或类。
即使已经发现某个分量超限，仍遍历其余单元、调用后续源项并检查合计，
避免漏掉原本应抛出的非法状态、非有限源项或回调异常。

每次 Riemann 求解检查波速，按面的**两侧各自完整局部步长**检查 `cfl_max`。
预测态和更新态都检查物理有效性。检查不通过就丢弃整个大步、\(H\) 减半并重新选层。
超出重试次数则报错。回调异常直接传播。正式网格和星区压力初值缓存均只在最终边界填充成功后提交。
边界/源项回调自身的外部副作用不属于可回滚状态。

压力缓存与 Euler、RK2 和 LTS Euler 共用 `hydro::StarPressureCache` 类型，
由它统一提供按方向的存储、初始化和清空操作。LTS RK2 仍自行控制子步更新、
周期面的同步、重试时恢复初始缓存及接受大步后的提交；不经过全局 RHS 调度。
外部调用者复用缓存时，更换模拟或重新划分网格后应调用 `clear()`。

## 成本与当前取舍

面通量只在负责该面的局部时间层求解。工作数组只在单次大步内复用，没有新增跨步 workspace。
为正确支持现有“输入整张网格”的源项和用户边界接口，阶段视图复制及源项仍是全网格扫描。
因此减少 Riemann 求解次数不等于同倍数的总耗时提升；大量细步和自引力源项可能成为主要开销。
该实现优先保持逻辑独立、时间一致性和可验证的二阶精度。

用户边界测试还检查完整活跃网格，包括远处慢单元，都处于传入时刻的预测状态。
